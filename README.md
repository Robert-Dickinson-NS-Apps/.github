> [!NOTE]
> This repo holds the **organization profile** and shared **community-health files**. No application code lives here.

## 📂 What's in here

| Path | 🎨 | What it does |
| --- | :---: | --- |
| `profile/README.md` | 🟢 | Renders as the **public org page**, the first thing visitors see |
| `FUNDING.yml` | 🟡 | Adds the **Sponsor** button across every repo |
| `SECURITY.md` | 🔴 | Default **security policy** |
| `CONTRIBUTING.md` | 🔵 | Default **contributing guide** |
| `CODE_OF_CONDUCT.md` | 🟣 | Default **code of conduct** |
| `ISSUE_TEMPLATE/` | 🟠 | Default **issue and PR templates** |

> [!TIP]
> Everything here works as an **org-wide default**. Any repo that lacks its own copy inherits these automatically. Set it once, apply it everywhere.
